# Computer Code Availability

The source code developed for this study is openly available in the public
GitHub repository **GeoMoE-ZW** at
https://github.com/YOUR_GITHUB_USERNAME/GeoMoE-ZW under the MIT License. The
repository can be accessed and downloaded anonymously and contains individual
source files, installation and usage instructions, dependency and computational
environment information, configuration files, a user guide, and a CPU-only
synthetic quick test (`python quick_run.py`). The quick test does not require
the study dataset, trained checkpoints, a GPU, or proprietary software. The
repository does not redistribute third-party vector geographic data or large
trained checkpoints; the corresponding limitations and the procedure required
for reproducing the formal experiments are documented in
`docs/REPRODUCIBILITY.md`.

Before submission, replace `YOUR_GITHUB_USERNAME` with the actual account name
and verify the public URL in a signed-out/incognito browser window.
